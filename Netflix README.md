Netflix Movies and TV Shows Clustering 🍿

📌 Project Overview

This project focuses on grouping Netflix's vast library of movies and TV shows into distinct clusters using Unsupervised Machine Learning. By analyzing features like genre, cast, and description, we aim to uncover hidden patterns in how content is categorized.

🛠️ Key Steps Involved

  Data Cleaning: Handled missing values in the 'Director' and 'Cast' columns.
  
  Text Preprocessing: Implemented TF-IDF Vectorization to process textual data from descriptions.

  Dimensionality Reduction: Used Principal Component Analysis (PCA) to simplify the dataset for better clustering results.

  Clustering Algorithms: Applied K-Means and Agglomerative Hierarchical Clustering.

  Evaluation: Used the Elbow Method and Silhouette Score to find the optimal number of clusters.

📈 Major Insights

  Identified 5-7 distinct clusters that categorize content by regional popularity and genre themes.

  Discovered a significant increase in international content on the platform over the last decade.

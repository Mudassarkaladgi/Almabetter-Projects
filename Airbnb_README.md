# Airbnb Booking Analysis 🏠📊

## Project Overview
This project performs an **Exploratory Data Analysis (EDA)** on Airbnb booking data to uncover key insights into pricing, guest behavior, and neighborhood popularity.

## Project Summary
Airbnb has revolutionized travel by offering unique, affordable lodging. This analysis explores a dataset of thousands of listings to help hosts optimize their pricing and guests find the best deals.

## Key Objectives
* Analyze the distribution of prices across different neighborhood groups.
* Identify the most preferred room types.
* Find correlations between availability, price, and number of reviews.
* Visualize the geographical distribution of listings.

## Technologies Used
* **Python**: Core programming language.
* **Pandas & NumPy**: Data manipulation and cleaning.
* **Matplotlib & Seaborn**: Data visualization.
* **Google Colab**: Development environment.

## How to Run
1. Clone the repository: `git clone https://github.com/Mudassarkaladgi/Almabetter-Projects.git`
2. Open `Airbnb_Booking_Analysis_1.ipynb` in Google Colab or Jupyter Notebook.
3. Run all cells to see the analysis and visualizations.
